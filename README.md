# Sales-Data-Analysis-and-Interactive-Dashboard
##  Project Overview

This project focuses on analyzing business sales data and building a professional interactive dashboard using Tableau. The dashboard helps organizations monitor sales performance, profitability, customer trends, and regional growth through data-driven visual insights.

The project demonstrates practical Data Analytics, Business Intelligence, and Dashboard Development skills commonly used in real-world business environments.

---

#  Objectives

* Analyze overall sales and profit performance
* Identify top-performing products and regions
* Track monthly and yearly revenue trends
* Understand customer purchasing behavior
* Detect low-profit categories and discount impact
* Create an interactive dashboard for business reporting

---

#  Tech Stack

* Tableau
* CSV Dataset
* Data Visualization Techniques
* Business Intelligence Concepts
---

#  Dataset Information

The dataset contains sales transaction records including:

| Column Name   | Description             |
| ------------- | ----------------------- |
| Order ID      | Unique order identifier |
| Order Date    | Purchase date           |
| Customer Name | Customer details        |
| Region        | Sales region            |
| Category      | Product category        |
| Product Name  | Product purchased       |
| Sales         | Revenue generated       |
| Quantity      | Units sold              |
| Profit        | Profit earned           |
| Discount      | Discount applied        |
