# Sales and Data Analysis Dashboard

## Project Overview

This project focuses on analyzing retail sales data and building an interactive Business Intelligence dashboard using Python, SQL, and Tableau.

The objective is to transform raw sales transaction data into actionable business insights by performing data cleaning, exploratory data analysis (EDA), SQL-based business reporting, and interactive dashboard development.

This project demonstrates end-to-end Data Analytics workflow commonly used in real-world business environments.

---

## Project Objectives

* Analyze overall sales and profitability
* Identify top-performing products and customer segments
* Evaluate regional sales performance
* Understand sales trends over time
* Measure discount impact on profit
* Create an interactive business dashboard for decision-making

## Key Business Insights

### Regional Performance

* West region generated the highest sales revenue.
* South region contributed the lowest revenue.

### Category Analysis

* Technology category generated the highest profit.
* Furniture category showed comparatively lower profitability.

### Customer Segments

* Consumer segment contributed the highest sales volume.
* Home Office segment generated the lowest revenue.

### Product Performance

* A small number of products contributed significantly to overall revenue.
* Top-performing products accounted for a large share of sales.

### Profitability

* Higher discounts negatively impacted profit margins.
* Certain products generated high sales but relatively low profits.
